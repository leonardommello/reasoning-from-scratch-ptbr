Build a Reasoning Model (From Scratch)

Tradução para português do Brasil do repositório de código de Sebastian Raschka: notebooks, guias de instalação e documentação para construir um modelo de raciocínio sobre um LLM base, do zero.

Leia antes de usar. Este site não é o livro, não é uma publicação oficial da Manning e não substitui a leitura da obra. É uma tradução não oficial, feita pela comunidade, do repositório de código licenciado sob Apache License 2.0 (Copyright 2025-2026 Sebastian Raschka). O texto do livro impresso não faz parte do repositório e não é reproduzido aqui. Se este material for útil para você, compre o livro — é ele que sustenta o trabalho original.

Capítulos

01 Entendendo modelos de raciocínio Sem código neste capítulo 02 Gerando texto com um LLM pré-treinado Instalação, tokenizer, KV caching, torch.compile 03 Avaliando modelos de raciocínio Verificador de matemática, MATH-500, normalização de respostas 04 Melhorando o raciocínio com inference-time scaling Chain-of-thought, temperature, top-p, self-consistency 05 Inference-time scaling via self-refinement Scores heurísticos, log-probabilidades, loop de refinamento 06 Treinando modelos de raciocínio com aprendizado por reforço RLVR, GRPO, rollouts, advantages, loop de treinamento 07 Melhorando o GRPO para aprendizado por reforço Métricas, policy ratios clipados, termo de KL, format reward 08 Destilando modelos de raciocínio para raciocínio eficiente Destilação hard e soft, dataset do professor, cross-entropy

Apêndices
